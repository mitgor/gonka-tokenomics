**Document structure:**

1. **Executive Summary** (300-400 words): Key finding — OpenClaw agents cost 3-10x more than chatbots due to heartbeat context resending, multi-step tool call chains, and always-on operation. The dominant cost driver is heartbeats (full context resend every 30 minutes = 48 calls/day minimum), not message volume. Gonka's potential cost advantage depends on final pricing (TBD) but its tiered routing and server-side sessions structurally reduce token consumption. Note: Gonka pricing is TBD; analysis uses scenario ranges.

2. **Methodology** (300-400 words): Explain:
   - Why per-task cost matters more than per-token cost for agent workloads
   - How OpenClaw agent cost is calculated: system prompt (~9,600 tokens/turn) + workspace context + heartbeat overhead + tool call chains
   - The 3 workload tiers being modeled and their parameters
   - Assumptions: 1 input token = 1 output token blended ratio unless provider-specific data available; heartbeat sends full system prompt + context; tool calls average 500 tokens input + 200 tokens output per call
   - Source citations for all baseline numbers

3. **Workload Tier Definitions** (400-500 words): Define exactly 3 tiers with these specific parameters:

   **Casual Tier:**
   - 1 agent, 1 channel (e.g., Telegram)
   - 50 user messages/day
   - 30-minute heartbeat interval (48 heartbeats/day)
   - ~9,600 tokens per turn (system prompt + context)
   - 3 tool calls per user message average
   - Single model (budget tier)
   - Daily token estimate: (50 messages x 9,600 tokens) + (48 heartbeats x 9,600 tokens) + (150 tool calls x 700 tokens) = 480K + 461K + 105K = ~1.05M tokens/day
   - Monthly: ~31.5M tokens

   **Active Tier:**
   - 3 agents, 2 channels each
   - 200 user messages/day total
   - 30-minute heartbeat interval (48 heartbeats/day x 6 channel-agents = 288 heartbeats/day)
   - 5 tool calls per message average
   - Multi-model routing (70% budget, 30% strong model)
   - Daily token estimate: (200 x 9,600) + (288 x 9,600) + (1,000 x 700) = 1.92M + 2.76M + 700K = ~5.38M tokens/day
   - Monthly: ~161M tokens

   **Heavy Tier:**
   - 10 agents, 3 channels each
   - 1,000+ user messages/day
   - 5-minute heartbeat interval (288 heartbeats/day x 30 channel-agents = 8,640 heartbeats/day)
   - 8 tool calls per message average
   - Always-on monitoring, premium models for complex tasks
   - Daily token estimate: (1,000 x 9,600) + (8,640 x 9,600) + (8,000 x 700) = 9.6M + 82.9M + 5.6M = ~98.1M tokens/day
   - Monthly: ~2.94B tokens

   Explain Gonka's three pricing scenarios: A (aggressive — 50% below cheapest verified), B (moderate — 30% below), C (conservative — price match). All are hypothetical until Gonka sets actual pricing.

5. **Hidden Cost Analysis** (500-700 words): For each provider, quantify hidden costs beyond headline per-token rates:

   **OpenRouter:**
   - 5.5% credit markup on all usage (buy $100 credits, get $94.50 of inference)
   - Free tier: requests queued behind paid users, models disappear/degrade
   - No prompt caching — every heartbeat resends full context at full price
   - Rate limiting on high-volume: throttled requests = wasted agent idle time

   **OpenAI:**
   - Prompt caching: automatic, 50% discount on cached tokens — heartbeat costs reduced ~50%
   - Volume discounts available but require commitment
   - No markup but premium model pricing ($2.50/$10 for GPT-4o)

   **Anthropic:**
   - Prompt caching: 90% discount on cache reads, but 25% write premium on first cache fill
   - Net effect on heartbeats: first heartbeat costs 25% more, subsequent ones cost 90% less
   - Rate limits tighter than OpenAI for high-volume agent workloads

   **Together AI:**
   - No markup (own GPU clusters), no caching, straightforward per-token
   - Lowest verified price for K2.5 ($0.50/$2.50)
   - No rate limit concerns at current scale

   **Gonka:**
   - Server-side sessions eliminate context resending — heartbeats send delta only, not full context
   - Tiered routing: 70% of requests to lite quantization (cheaper) when quality allows
   - No markup (own decentralized network)
   - Hidden ADVANTAGE: session persistence = effectively free "prompt caching" since context stays server-side
   - Quantify: if sessions reduce heartbeat token overhead by 80%, Casual tier drops from 31.5M to ~12M tokens/month

   - Gonka Scenario A: ~$24/mo raw → ~$10/mo adjusted (session persistence eliminates heartbeat overhead)
   - Gonka Scenario B: ~$33/mo raw → ~$14/mo adjusted
   - Gonka Scenario C: ~$43/mo raw → ~$17/mo adjusted

   Show the math for each calculation. Repeat for Active and Heavy tiers with proportional scaling. Note that session persistence advantage grows with heartbeat frequency (5-min heartbeats in Heavy tier = 6x more savings).

7. **At-Scale Economics** (400-500 words): What happens at 100+ agents? Key dynamics:
   - OpenRouter: linear cost scaling, no volume discounts
   - OpenAI/Anthropic: potential enterprise agreements, but premium pricing makes scale expensive
   - Together AI: competitive at scale, own infrastructure
   - Gonka: decentralized network scales with GNK token economics; marginal cost potentially decreases as network grows (more miners = more supply = lower prices). Flag this as theoretical — depends on network growth assumptions.

8. **Where Gonka Wins and Where It Does Not** (300-400 words): Honest assessment:
   - WINS: Agent workloads with frequent heartbeats (sessions eliminate context resending), budget-conscious casual users (if pricing is aggressive), privacy-sensitive workloads (decentralized)
   - DOES NOT WIN: Users who need multiple models (K2.5 only), users who need enterprise SLAs, users already locked into OpenAI/Anthropic prompt caching ecosystems, cost-sensitive users if Gonka prices at or above DeepInfra
   - DEPENDS ON PRICING: Everything in the "cost advantage" narrative hinges on Gonka setting pricing below Together AI/DeepInfra. If priced at parity, the advantage is sessions and privacy only.

9. **Pricing Recommendations for Leadership** (200-300 words): Based on the analysis, suggest:
   - Scenario B ($0.35/$1.75) as the recommended target: 30% below DeepInfra, competitive with Together AI when session savings are included
   - Must publish pricing before any GTM activity — competitors have public pricing pages
   - Consider a free tier (e.g., 1M tokens/month free) to eliminate signup friction for Casual tier users
   - Session savings should be the headline pricing story, not raw per-token rates
