**Function: `build_assumptions_tab(wb)`**

This function:
1. Takes an openpyxl Workbook (already created)
2. Calls `register_styles(wb)` to register all NamedStyles
3. Gets or creates the active worksheet, renames it to "Assumptions"
4. Sets the tab color to blue (TAB_COLOR_INPUT)
5. Writes a merged header row: "GONKA TOKENOMICS MODEL - ASSUMPTIONS" in row 1 (merge A1:E1), apply section_header style
6. Writes instruction row 2: "All blue-shaded cells below are adjustable inputs" (merge A2:E2)
7. Row 3: blank separator
8. Starting from row 4, iterates through PARAM_GROUPS:
   - For each group: writes a section header row (group name in column A, apply section_header style, merge A:E)
   - For each parameter in the group: writes a data row:
     - Column A: Parameter name (locked)
     - Column B: Parameter value (UNLOCKED -- this is the editable input cell, apply input_cell style, then apply the appropriate number format from FORMAT_TO_STYLE based on param["format"])
     - Column C: Unit string (locked)
     - Column D: Source citation (locked)
   - After each group: blank separator row
9. Builds and returns `param_refs` dict: `{"Total Supply": "Assumptions!$B$5", "Decay Rate": "Assumptions!$B$12", ...}` mapping each parameter name to its absolute cell reference
10. Sets column widths: A=35, B=20, C=15, D=30
11. Freezes panes at A4 (header rows always visible)
12. Does NOT apply sheet protection yet (that's a Phase 9 concern) but DOES apply Protection(locked=False) to each input cell in column B so protection will work correctly when enabled later

**Column layout (matching ARCHITECTURE.md spec):**
| Column A | Column B | Column C | Column D |
|----------|----------|----------|----------|
| Parameter name | Value (EDITABLE, blue) | Unit | Source/Note |

**param_refs dict construction:**
For each parameter written to the sheet, record the cell address where the VALUE was written (column B). Use absolute references with the sheet name:
```python
row_num = current_row  # The row where this param's value is
param_refs[param["name"]] = f"Assumptions!$B${row_num}"
```

**Style application per cell type:**
- Column A cells: no special style (default font, locked)
- Column B cells: apply `input_cell` style first, then override `cell.number_format` based on FORMAT_TO_STYLE[param["format"]]. Apply `Protection(locked=False)`.
- Column C cells: no special style (default font, locked)
- Column D cells: no special style, italic font for source citations

**Section header rows:**
- Merge A:D for the section header
- Apply `section_header` named style to the merged cell
- Section header text is the group name from PARAM_GROUPS keys (e.g., "TOKEN SUPPLY", "EMISSION PARAMETERS")

**IMPORTANT:** The param_refs dict is THE critical output. Every future model module (emission.py, fee_transition.py, etc.) will receive this dict and use it to write formulas like `=Assumptions!$B$12*EXP(-Assumptions!$B$13*B3)`. If param_refs maps names to wrong cells, every downstream formula breaks.

**IMPORTANT:** Use direct cell references (Assumptions!$B$12), NOT named ranges. Per SUMMARY.md resolved conflict: "Use direct cell references as the primary approach. Named ranges add debugging complexity."

**IMPORTANT:** Do NOT compute any values in this module. Parameters are written as literal Python values to cells. Excel formulas are NOT written here -- that happens in model modules (Phase 2+).

```python
def create_workbook():
```

```python
#!/usr/bin/env python3
"""
Gonka Tokenomics Model Generator

Generates Excel workbooks (.xlsx) for Gonka Network tokenomics modeling.
All parameters from v1.0 research are written to an Assumptions tab that
drives all downstream calculations via Excel formulas.

Usage:
    python generate.py              # Generate all workbooks
    python generate.py --test       # Generate minimal test workbook (Assumptions only)

Output directory: ./output/
"""
import sys
import os
from pathlib import Path

def main():
    # Ensure output directory exists
    output_dir = Path("output")
    output_dir.mkdir(exist_ok=True)

    # Parse args
    test_mode = "--test" in sys.argv

    if test_mode:
        generate_test()
    else:
        generate_all()

def generate_test():
    """Generate a minimal test workbook with only the Assumptions tab."""
    from generators.workbook_base import create_workbook

    wb, param_refs = create_workbook()

    output_path = Path("output") / "gonka_test_assumptions.xlsx"
    wb.save(str(output_path))
    print(f"Generated: {output_path}")
    print(f"  Assumptions tab: {len(param_refs)} parameters")

def generate_all():
    """Generate all workbooks. Currently generates master workbook skeleton."""
    from generators.workbook_base import create_workbook

    wb, param_refs = create_workbook()

    # Future phases will add model tabs here:
    # Phase 2: emission.build_emission_tab(ws, param_refs)
    # Phase 3: token_price.build_token_price_tab(ws, param_refs)
    # Phase 4: fee_transition.build_fee_transition_tab(ws, param_refs, emission_meta)
    # Phase 5: host_profit.build_host_profit_tab(ws, param_refs, emission_meta, price_meta)
    # Phase 6: treasury.build_treasury_tab(ws, param_refs)

    output_path = Path("output") / "gonka_master_model.xlsx"
    wb.save(str(output_path))
    print(f"Generated: {output_path}")
    print(f"  Assumptions tab: {len(param_refs)} parameters")
    print(f"  Model tabs: (none yet -- added in Phase 2+)")

if __name__ == "__main__":
    main()
```

**IMPORTANT:** The generate.py file imports from generators and models -- it must be run from the project root directory. Do NOT add sys.path hacks. The project is designed to be run as `python generate.py` from the repo root.

**IMPORTANT:** The `--test` flag generates a minimal workbook for quick verification. The default (no flag) generates the master workbook, which currently has only the Assumptions tab but will grow in future phases.
