```python
def _add_back_to_doc_links(wb):
    """Add 'Back to Documentation' hyperlink on every non-Documentation tab."""
    from openpyxl.styles import Font
    link_font = Font(name="Calibri", size=11, color="0563C1", underline="single")

    # Per-tab safe positions (column just after merge end, row 1)
    # These columns are BEFORE chart start columns, avoiding conflicts
    BACK_LINK_POSITIONS = {
        "Assumptions": ("F", 1),       # Merge A1:E1, charts: none
        "Emission Schedule": ("K", 1), # Merge A1:J1, charts at K1 -- use row 2 instead
        "Token Price": ("M", 1),       # Merge A1:L1, charts at N1
        "Fee Transition": ("O", 1),    # Merge A1:N1, charts at P1
        "Host Profitability": ("N", 1),# Merge A1:M1, charts at O1
        "Treasury & POL": ("O", 1),    # Merge A1:N1, charts at P1
        "Dashboard": ("A", 1),         # No merge expected yet (Plan 02 builds content)
    }
```

IMPORTANT: For Emission Schedule, the chart starts at K1, which overlaps. Use row 2 for that tab only OR place at K1 since the chart will cover it visually. The safest approach: place the link in column that is 1 past the merge end for each tab. For Emission Schedule specifically, charts anchor at K1 but the link cell at K1 still works -- Excel renders the chart OVER the cell, and clicking "Back to Documentation" still works if the user clicks the cell itself (not the chart). Alternatively, use row 2 for Emission Schedule only.

Simpler approach -- use a consistent strategy: For each tab, find the column right after the merge end column. If that column is the chart start column, use the same column but row 2 instead of row 1.

```python
    BACK_LINK_COL_ROW = {
        "Assumptions": (6, 1),          # F1 (after A1:E1 merge)
        "Emission Schedule": (11, 2),   # K2 (K1 is chart anchor; use row 2)
        "Token Price": (13, 1),         # M1 (after A1:L1 merge, before N1 chart)
        "Fee Transition": (15, 1),      # O1 (after A1:N1 merge, before P1 chart)
        "Host Profitability": (14, 1),  # N1 (after A1:M1 merge, before O1 chart)
        "Treasury & POL": (15, 1),      # O1 (after A1:N1 merge, before P1 chart)
        "Dashboard": (1, 1),            # A1 temporarily; Plan 02 will handle
    }

    for ws in wb.worksheets:
        if ws.title == "Documentation":
            continue
        if ws.title in BACK_LINK_COL_ROW:
            col, row = BACK_LINK_COL_ROW[ws.title]
        else:
            col, row = 1, 1
        cell = ws.cell(row=row, column=col)
        cell.value = "<< Documentation"
        cell.hyperlink = "#Documentation!A1"
        cell.font = link_font
```
