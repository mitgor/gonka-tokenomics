  The function adds a new section "SCENARIO SELECTOR" after all PARAM_GROUPS. Specifically:

  1. **Section header row** (merged A:D, "SCENARIO SELECTOR", section_header style)

  2. **Active Scenario row** (current_row + 1):

     - B: "Base" (default value, input_cell style, Protection(locked=False))

     - A: "Scenario Index"
     - B: `=MATCH(B{selector_row},{"Conservative","Base","Aggressive"},0)` -- returns 1, 2, or 3
     - Style: formula_cell
     - CRITICAL: The curly braces `{}` in the MATCH formula are Excel array delimiters, NOT Python format placeholders. Use an f-string with the row number inserted separately: `f'=MATCH(B{selector_row},{{"Conservative","Base","Aggressive"}},0)'`
     - Add to param_refs: `"Scenario Index"` -> `"Assumptions!$B${row}"`

  4. **Active Price Low row** (current_row + 3):
     - A: "Active Price Low"
     - B: `=CHOOSE($B${index_row},{param_refs["Conservative Price Low"]},{param_refs["Moderate Price Low"]},{param_refs["Aggressive Price Low"]})`
     - Style: formula_cell, number_format: "$#,##0.00" (currency_precise)
     - Add to param_refs: `"Active Price Low"` -> `"Assumptions!$B${row}"`

  5. **Active Price High row** (current_row + 4):
     - A: "Active Price High"
     - B: `=CHOOSE($B${index_row},{param_refs["Conservative Price High"]},{param_refs["Moderate Price High"]},{param_refs["Aggressive Price High"]})`
     - Style: formula_cell, number_format: "$#,##0.00" (currency_precise)

  Create `generators/token_price.py` following the Phase 2 `build_emission_tab()` pattern.

  **Public API:**

  **Imports:**
  ```python

  ```

  **Tab setup:**
  - Create sheet: `wb.create_sheet(title="Token Price")`
  - Tab color: `TAB_COLOR_CALC` (gray, same as Emission Schedule)
  - Row 1: Merged A1:L1 title "TOKEN PRICE SCENARIOS MODEL", section_header style
  - Row 2: Column headers (see below), header style
  - Freeze panes at A3

  **Column layout (A through L):**

  | Col | Header | Formula | Style |
  |-----|--------|---------|-------|
  | A | Period Label | Copy from Emission Schedule (text, not formula): use `_build_periods()` same as emission.py or use cross-ref `='Emission Schedule'!A{es_row}`. Recommendation: use cross-ref for consistency | crossref_cell |
  | B | Conservative ($) | `={param_refs["Conservative Price Low"]}+({i}/31)*({param_refs["Conservative Price High"]}-{param_refs["Conservative Price Low"]})` where i = 0..31 (row index) | currency_precise |
  | C | Moderate ($) | `={param_refs["Moderate Price Low"]}+({i}/31)*({param_refs["Moderate Price High"]}-{param_refs["Moderate Price Low"]})` | currency_precise |
  | D | Aggressive ($) | `={param_refs["Aggressive Price Low"]}+({i}/31)*({param_refs["Aggressive Price High"]}-{param_refs["Aggressive Price Low"]})` | currency_precise |
  | E | Bitfury ($) | `={param_refs["Bitfury Schelling Point"]}` (constant flat line) | currency_precise |
  | F | Active Price ($) | `={param_refs["Active Price Low"]}+({i}/31)*({param_refs["Active Price High"]}-{param_refs["Active Price Low"]})` | currency_precise |
  | G | Circulating Supply | `={es_sheet}!{circ_col}{es_row}` (cross-sheet ref to Emission Schedule col H) | crossref_cell with tokens number_format |
  | H | FDV ($) | `={param_refs["Total Supply"]}*F{row}` | currency |
  | I | Circ. Market Cap ($) | `=G{row}*F{row}` | currency |
  | J | Gross New Supply | `={es_sheet}!{total_col}{es_row}` (cross-sheet ref to Emission Schedule col G) | crossref_cell with tokens number_format |
  | K | Buyback Burn (GNK) | `={param_refs["Assumed Annual Fee Revenue"]}*{param_refs["Buyback-Burn"]}/F{row}/{periods_per_year}` | tokens |
  | L | Net Supply Change | `=J{row}-K{row}` | tokens |

  **Important details for columns:**

  - **Column A (Period Label):** Use cross-sheet reference: `='{es_sheet}'!A{es_row}` to keep labels in sync. Style as crossref_cell.

  - **Columns B-E (Price trajectories):** Use linear interpolation `price_low + (i/31) * (price_high - price_low)` where `i` is the 0-based row index (0 for first data row, 31 for last). All param refs point to Assumptions tab. The number_format for these should be `"$#,##0.00"` -- apply currency_precise style.

  - **Column F (Active Price):** Same interpolation formula but using `param_refs["Active Price Low"]` and `param_refs["Active Price High"]` which are the CHOOSE formulas on Assumptions that switch based on dropdown.

  - **Column G (Circulating Supply):** Cross-sheet reference. Use `quote_sheetname(emission_meta["sheet_name"])` to get `"'Emission Schedule'"`. Reference column H (cumulative_circulating) from emission_meta. Apply crossref_cell style, then override number_format to "#,##0" (tokens format).

  - **Column H (FDV):** FDV = Total Supply * Active Price. Total Supply from param_refs, Active Price from column F same row.

  - **Column I (Circ Market Cap):** = G{row} * F{row}. Simple within-row reference.

  - **Column J (Gross New Supply):** Cross-sheet reference to Emission Schedule column G (total_new). Same crossref_cell + tokens format treatment as column G.

  - **Column K (Buyback Burn Tokens):** The formula converts annual USD fee revenue to tokens burned per period:
    - For monthly periods (i=0..23): divide annual fee by 12 -> `{fee_rev_ref}*{buyback_ref}/F{row}/12`
    - For annual periods (i=24..31): use annual fee directly -> `{fee_rev_ref}*{buyback_ref}/F{row}`
    - This aligns with the period structure: Y1-Y2 are monthly, Y3-Y10 are annual
    - Style: tokens

  - **Column L (Net Supply Change):** `=J{row}-K{row}`. Gross new supply minus tokens burned. When negative, supply is deflationary. Style: tokens.
