    - Proof point (specific number, benchmark, or architectural fact)

    - Persona-specific positioning statement (one sentence)
    - Top 3 messages ranked by that persona's decision drivers (cost for Weekend Builder, reliability for Startup CTO, privacy/censorship for Privacy-First Builder)
    - "Lead with" and "Never lead with" guidance specific to each persona
    - One elevator pitch (30 seconds / 2-3 sentences) tailored to their language

    **5. Architecture-to-Message Mapping** — Complete table mapping EVERY Gonka technical feature to a developer benefit statement. Use the mapping table from ARCHITECTURE.md Section "Mapping Table" as the skeleton, but:
    - Rewrite "Marketing Message" column to be more natural (conversational, not tagline-y)
    - Add a "Proof Point" column with specific numbers from pricing analysis and benchmarks
    - Add a "Competitive Context" column noting which competitors lack this feature (from competitive matrix)

    **6. Vocabulary Guidelines** — Two sub-sections:
    - **Never-Say List**: Table with columns "Internal Term", "Why It Alienates", "Developer-Facing Alternative". Include at minimum: staking, epochs, validators, gas, slashing, governance proposals, DePIN, Web3, tokenomics, consensus mechanism, mining, on-chain, wallet. Source from PITFALLS.md Pitfall 7.
    - **Approved Vocabulary**: Table with columns "Concept", "Approved Term", "Usage Example". Map every crypto/blockchain concept that might appear in developer-facing content to its approved alternative.
    - **Context Rules**: When crypto terms ARE acceptable (e.g., in a "How It Works Under the Hood" section for curious developers, in investor-facing materials, in GPU host documentation).

    - Startup CTO: Gonka vs Together AI (the performance/reliability pick)
    - Privacy-First Builder: Gonka vs Akash Network (the decentralized alternative)
    Each statement: "Unlike [competitor] which [limitation], Gonka [advantage] so you can [outcome]."

    - Use markdown headers, tables, and blockquotes
    - Include a "Version" and "Date" header
    - Include "Feeds into" noting Phase 18 (Channel Strategy) and Phase 19 (Partnership)
    - Every claim must have a parenthetical source citation (e.g., "(competitive matrix: Agent Sessions — WIN)")
