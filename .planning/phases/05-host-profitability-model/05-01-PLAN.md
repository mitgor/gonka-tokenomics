**Row 1:** Merged title "HOST PROFITABILITY MODEL" (A1:M1), style "section_header".

**Row 2:** Column headers from _HEADERS, style "header".

**Rows 3-34 (32 data rows):** For each row `i` (0-based), `row = 3 + i`, `es_row = emission_meta["data_start_row"] + i`, `tp_row = price_meta["data_start_row"] + i`, `ft_row = fee_meta["data_start_row"] + i`:

Determine `days` per period:
- i=0..23 (monthly): days=30
- i=24..31 (annual): days=365

**Column A (Period Label):** Cross-ref from Emission Schedule.
```
={es_sheet}!{es_period_col}{es_row}
```
Style: `crossref_cell`

**Column B (Mining GNK per Host):** Total mining emission / host count.
```
={es_sheet}!{es_mining_col}{es_row}/{hosts_ref}
```
Style: `tokens`

**Column C (Mining Income per Host $):** Mining GNK * active price.
```
=B{row}*{tp_sheet}!{tp_active_col}{tp_row}
```
Style: `currency`

**Column D (Fee Income per Host $):** Total host share from Fee Transition / host count.
```
={ft_sheet}!{ft_host_share_col}{ft_row}/{hosts_ref}
```
Style: `currency`

**Column E (Total Gonka Income $):** Sum of mining + fee income per host.
```
=C{row}+D{row}
```
Style: `currency`

**Column F (Electricity Cost $):** Electricity rate * GPU power * 24hrs * days / 1000 (W->kW) * GPUs per host.
```
={elec_mid_ref}*{gpu_power_ref}*24*{days}/1000*({gpus_ref}/{hosts_ref})
```
Style: `currency`

**Column G (Net Income $):** Total Gonka income minus electricity.
```
=E{row}-F{row}
```
Style: `currency`

**Column H (Traditional Rental $):** Lambda rental rate * 24hrs * days * GPUs per host.
Uses Lambda as the primary benchmark (on-demand, most comparable to Gonka's flexible hosting).
```
={lambda_ref}*24*{days}*({gpus_ref}/{hosts_ref})
```
Style: `currency`

**Column I (Gonka vs Traditional $):** Total Gonka income minus traditional rental.
Compares gross Gonka income (E) to traditional rental (H), since traditional rental prices already include provider electricity costs.
```
=E{row}-H{row}
```
Style: `currency`

**Column J (Breakeven GNK Price $):** Price at which Gonka hosting breaks even.
`= MAX(0, (traditional_rental - fee_income) / mining_GNK_per_host)`. When fee income exceeds rental, breakeven is 0 (already profitable from fees alone). IFERROR handles division by near-zero mining.
```
=IFERROR(MAX(0,(H{row}-D{row})/B{row}),99999)
```
Style: `currency`

**Column K (Breakeven Reference Low $):** Static $0.85 reference.
```
0.85
```
Style: `currency`

**Column L (Breakeven Reference High $):** Static $3.30 reference.
```
3.30
```
Style: `currency`

**Column M (Churn Risk Flag):** 1 if Gonka income < traditional rental, 0 otherwise.
```
=IF(E{row}<H{row},1,0)
```
Style: `integer`

**Below-Data Section 1: HOST ROI SENSITIVITY TABLE (rows 36-43)**

Row 35: Blank separator.

Row 36: Section header "HOST ROI SENSITIVITY (Year 10 Monthly Profit per Host)" merged A36:F36, style "section_header".

Row 37: Sub-header: A37="GNK Price \\ GPUs", B37="1,000 GPUs", C37="5,000 GPUs", D37="10,000 GPUs", E37="25,000 GPUs", F37="50,000 GPUs". Style: "header".

Rows 38-43: 6 rows x 5 columns. Row labels in column A:
- Row 38: "$0.50"
- Row 39: "$1.00"
- Row 40: "$2.00"
- Row 41: "$3.00"
- Row 42: "$5.00"
- Row 43: "$10.00"

GNK prices: `[0.50, 1.00, 2.00, 3.00, 5.00, 10.00]`
GPU counts: `[1000, 5000, 10000, 25000, 50000]`

Each cell formula computes monthly host profit at Year 10 (uses 30-day month for monthly comparison):

```
=({es_sheet}!{es_mining_col}{yr10_es_row}/{gpu_count}*({gpus_ref}/{hosts_ref})*{gnk_price}
  +{ft_sheet}!{ft_host_share_col}{yr10_ft_row}/(({gpu_count}/({gpus_ref}/{hosts_ref})))
  *30/365)
  -{elec_mid_ref}*{gpu_power_ref}*24*30/1000*({gpus_ref}/{hosts_ref})
```

Where `yr10_es_row = emission_meta["data_end_row"]` (34), `yr10_ft_row = fee_meta["data_end_row"]` (34).

**CRITICAL per-host division:** The emission at Year 10 is total network emission for a 365-day period. Per-host monthly mining income = `total_emission / gpu_count * gpus_per_host * gnk_price * 30/365`. Fee host share at Year 10 is also for 365 days, so scale by 30/365. Number of hosts = `gpu_count / gpus_per_host`.

Refined formula per cell:
```python
gpus_per_host = f"({gpus_ref}/{hosts_ref})"
# mining income: (total_emission_yr10 * 30/365) / gpu_count * gpus_per_host * gnk_price
# fee income: (fee_host_share_yr10 * 30/365) / (gpu_count / gpus_per_host)
# electricity: elec_mid * gpu_power * 24 * 30 / 1000 * gpus_per_host

formula = (
    f"=({es_sheet}!{es_mining_col}{yr10_es_row}*30/365/{gpu_count}*{gpus_per_host}*{gnk_price}"
    f"+{ft_sheet}!{ft_host_share_col}{yr10_ft_row}*30/365/({gpu_count}/{gpus_per_host}))"
    f"-{elec_mid_ref}*{gpu_power_ref}*24*30/1000*{gpus_per_host}"
)
```

Style: `currency`

Row 44: Annotation cell A44: "* Fee revenue held at base growth scenario. Larger networks may generate proportionally more fees." Style: italic font.

## Anti-Patterns to Avoid

- **Do NOT hardcode parameter values** -- every value must come from param_refs or cross-sheet references
- **Do NOT forget to divide fee host share by host count** -- Fee Transition K column shows TOTAL network host revenue, must divide by Current Hosts for per-host
- **Do NOT forget the days factor** -- monthly periods = 30 days, annual = 365 days for cost/revenue calculations
- **Do NOT forget IFERROR on breakeven formula** -- division by near-zero mining GNK produces errors in later periods
- **Do NOT forget quote_sheetname()** -- "Emission Schedule", "Token Price", "Fee Transition" all have spaces
- **Do NOT create charts or conditional formatting** -- that is Plan 02's scope
- **Do NOT import chart/formatting modules** -- keep Plan 01 focused on data model only
- **Do NOT scale fee revenue with network size in sensitivity table** -- keep fee constant at base scenario, add annotation
- **Do NOT use named ranges** -- use direct cell references (project convention)
- **Do NOT mix up Emission Schedule row alignment** -- es_row, tp_row, ft_row all have same data_start_row=3, so they align perfectly (i + data_start_row for each)
