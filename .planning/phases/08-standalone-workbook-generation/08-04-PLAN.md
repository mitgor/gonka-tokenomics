Create `generators/standalone.py` with a main function `generate_standalones()` and a per-workbook function `generate_standalone(config_key)`.

**Module structure:**

```python
"""
Gonka Tokenomics - Standalone Workbook Generator

Generates 4 focused standalone workbooks from the same builders used
by the master workbook. Each standalone has filtered assumptions
containing only the parameters relevant to its model chain.

Public API:
    generate_standalones() -> dict  # generates all 4 standalones
    generate_standalone(config_key) -> str  # generates one standalone
"""
```

**generate_standalone(config_key):**

1. Look up config from STANDALONE_CONFIGS[config_key]
2. Create fresh Workbook: `wb = Workbook()`
3. Build filtered Assumptions tab:
   ```python
   param_refs = build_filtered_assumptions_tab(
       wb,
       param_names=config["params"],
       include_scenario_selector=True,
       include_tail_toggle=config.get("include_tail_toggle", False),
       include_toggles=config.get("toggles", []),
   )
   ```
4. Build model tabs in dependency order based on config["builders"]:
   ```python
   meta = {}
   for builder_name in config["builders"]:
       if builder_name == "emission":
           meta["emission"] = build_emission_tab(wb, param_refs)
       elif builder_name == "token_price":
           meta["token_price"] = build_token_price_tab(wb, param_refs, meta["emission"])
       elif builder_name == "fee_transition":
           meta["fee_transition"] = build_fee_transition_tab(wb, param_refs, meta["emission"], meta["token_price"])
       elif builder_name == "host_profitability":
           meta["host_profitability"] = build_host_profit_tab(wb, param_refs, meta["emission"], meta["token_price"], meta["fee_transition"])
       elif builder_name == "treasury":
           meta["treasury"] = build_treasury_tab(wb, param_refs, meta["emission"], meta["token_price"], meta["fee_transition"])
   ```

5. Build glossary tab:
   ```python
   build_glossary_tab(wb, GLOSSARY_TERMS)
   ```

6. Build cover sheet (Documentation tab at index 0):
   - Compute tab_names for TOC: list of all sheet names EXCEPT "Documentation" itself, in the order they appear
   ```python
   tab_names = [ws.title for ws in wb.worksheets if ws.title != "Documentation"]
   build_cover_sheet(wb, config["title"], VERSION_INFO, tab_names, config.get("narratives"))
   ```

7. Verify tab order: Documentation should be first, then Assumptions, then model tabs in order, then Definitions last.
   ```python
   assert wb.worksheets[0].title == "Documentation"
   assert wb.worksheets[1].title == "Assumptions"
   assert wb.worksheets[-1].title == "Definitions"
   ```

8. Add "Back to Documentation" links on non-Documentation tabs (similar to generate.py's _add_back_to_doc_links but for standalone tab structure). For each non-Documentation tab, add a hyperlink cell. Use the same LINK_FONT pattern. Place links in a consistent position that doesn't conflict with content:
   - Assumptions: F1 (after header merge)
   - Model tabs: use same BACK_LINK_COL_ROW positions as master for matching tabs
   - Definitions: A1 or similar (no content conflicts)

9. Save workbook:
   ```python
   output_path = Path("output") / config["filename"]
   wb.save(str(output_path))
   fix_chart_rendering(str(output_path))
   ```

10. Return output_path as string for logging.

**generate_standalones():**
Loop over all 4 config keys in STANDALONE_CONFIGS, call generate_standalone() for each, print summary. Return dict of {config_key: output_path}.
