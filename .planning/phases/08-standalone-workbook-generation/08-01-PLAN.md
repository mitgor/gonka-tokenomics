Implementation:

1. Call `register_styles(wb)` (same as build_assumptions_tab).
2. Get active worksheet, rename to "Assumptions", set tab color to TAB_COLOR_INPUT.
3. Write header rows 1-3 identical to build_assumptions_tab (title merge, instruction text, blank row 3).
4. Initialize `param_refs = {}` and `current_row = 4`.
5. Loop over `PARAM_GROUPS.items()`:
   - Filter: `filtered_params = [p for p in params if p["name"] in param_names]`
   - Skip group if `filtered_params` is empty
   - Write section header (merged A:D, section_header style) -- same as build_assumptions_tab
   - Write each parameter row (A=name, B=value with input_cell style + number_format override + Protection(locked=False), C=unit, D=source with italic font) -- identical logic to build_assumptions_tab
   - Record `param_refs[param["name"]] = f"Assumptions!$B${current_row}"`
   - Blank separator row after each group
6. If `include_tail_toggle` is True and "Tail Emission Toggle" is in param_refs: call `_add_tail_emission_toggle(ws, param_refs)`.
7. If `include_toggles` is not None: for each toggle name in the list, add Y/N DataValidation to that toggle's cell (parse row from param_refs, same pattern as _add_tail_emission_toggle but with formula1='"Y,N"' and appropriate prompt text). The toggle cell already has its value written from the PARAM_GROUPS loop above.
8. If `include_scenario_selector` is True: call `_add_scenario_selector(ws, current_row, param_refs)`. CRITICAL: This requires the 6 price scenario params (Conservative/Moderate/Aggressive Price Low/High) to be in param_names. If they are not all present, skip the scenario selector and log a warning.
9. Set column widths (same _COL_WIDTHS dict).
10. Freeze panes at A4.
11. Return param_refs.

IMPORTANT: Do NOT modify build_assumptions_tab() or create_workbook(). They must continue working exactly as before for the master workbook. build_filtered_assumptions_tab is a NEW additional function.

IMPORTANT: The _add_tail_emission_toggle function uses formula1='"ON,OFF"'. The new what-if toggles use formula1='"Y,N"'. These are intentionally different (tail emission toggle existed before with ON/OFF convention; new toggles use Y/N per research recommendation).
