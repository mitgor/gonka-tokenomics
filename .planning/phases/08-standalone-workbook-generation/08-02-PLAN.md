```python
def build_glossary_tab(wb, terms):
    """Build a Definitions/Glossary tab with alphabetical entries.

    Args:
        wb: openpyxl Workbook (styles already registered).
        terms: dict of {term: definition} to display.

    Returns:
        None -- modifies wb in-place.
    """
```

Implementation:

1. Create sheet: `ws = wb.create_sheet("Definitions")`
2. Set tab color to a neutral gray or documentation color (use TAB_COLOR_DOCS from styles.py for consistency).
3. **Title row (row 1)**: Merge A1:C1, write "DEFINITIONS / GLOSSARY", apply "section_header" style.
4. **Blank row 2** as separator.
5. **Column headers (row 3)**: A3 = "Term" with "header" style, B3 = "Definition" with "header" style.
6. **Data rows (row 4+)**: Iterate over `sorted(terms.keys())`. For each term:
   - A = term name, bold font (Font(name="Calibri", size=11, bold=True))
   - B = definition text, normal font, text wrap enabled (Alignment(wrap_text=True, vertical="top"))
7. **Column widths**: A=30, B=80, C=15 (C is spare).
8. **Row heights**: Set each data row height to accommodate wrapped text -- use a heuristic like `max(15, len(definition) // 80 * 15 + 15)` or just set a fixed row height of 30 for readability.
9. **Freeze panes** at A4 (header row always visible).

Import only from openpyxl.styles and generators.styles. Follow the same import pattern as documentation.py.

Do NOT import GLOSSARY_TERMS from standalone_config.py in this module. The terms dict is passed as a parameter -- this keeps the builder reusable and decoupled from config.

Create `generators/cover_sheet.py` with a single public function:

```python
def build_cover_sheet(wb, title, version_info, tab_names, scenario_narratives=None):
    """Build a Documentation (cover) sheet for standalone workbooks.

    Args:
        wb: openpyxl Workbook (styles already registered).
        title: Model-specific title (e.g., "Token Price Model").
        version_info: dict with "version" (str) and "changelog" (list of (ver, date, desc) tuples).
        tab_names: List of tab names for the TOC (excluding Documentation itself).
        scenario_narratives: Optional dict of {"Conservative": "...", "Base": "...", "Aggressive": "..."}.

    Returns:
        None -- modifies wb in-place.
    """
```

This follows the existing documentation.py pattern but adds standalone-specific features.

Implementation:

1. Create sheet at index 0: `ws = wb.create_sheet("Documentation", index=0)`
2. Set tab color to TAB_COLOR_DOCS.

**Section 1: Title (rows 1-2)** -- same pattern as documentation.py:
- A1:F1 merged, "GONKA TOKENOMICS MODEL" in large bold font
- A2:F2 merged, model-specific subtitle using the `title` parameter (e.g., "Token Price Model -- Standalone Workbook")

**Section 2: Version and Date (rows 4-5)**:
- Row 4: "Version:" bold label in A4, version_info["version"] in B4
- Row 5: "Generated:" bold label in A5, "=TODAY()" formula in B5 with YYYY-MM-DD format

**Section 3: Disclaimer (row 7)** -- same as documentation.py:
- A7:F7 merged, "For internal decision-making purposes only" in red italic

**Section 4: Changelog (rows 9+)** -- NEW for standalones:
- Row 9: "CHANGELOG" with "section_header" style
- Row 10: Column headers: A="Version" (bold), B="Date" (bold), C="Description" (bold)
- Row 11+: One row per changelog entry from version_info["changelog"]
- Track current_row after this section

**Section 5: Scenario Narratives (if provided)** -- NEW for REQ-D03:
- current_row + 1 blank separator
- "SCENARIO NARRATIVES" with "section_header" style
- For each scenario in ["Conservative", "Base", "Aggressive"]:
  - A: scenario name in bold
  - B-E: narrative text merged across columns, with text wrap
  - Separate row per scenario with 1 blank row between

**Section 6: Table of Contents** -- similar to documentation.py:
- "TABLE OF CONTENTS" with "section_header" style
- Numbered hyperlinks to each tab (using quote_sheetname pattern from documentation.py)
- Brief descriptions (can use a simplified dict or just the tab name)

**Section 7: Color Convention Legend** -- same as documentation.py:
- "COLOR CONVENTIONS" header
- Same 5 legend entries with sample cells

**Column widths**: A=35, B=25, C=20, D=15, E=15, F=15.

Import Font, Alignment from openpyxl.styles. Import quote_sheetname from openpyxl.utils. Import TAB_COLOR_DOCS, SECTION_FONT_COLOR from generators.styles. Import LINK_FONT pattern (or redefine locally like documentation.py does).

IMPORTANT: The cover_sheet.py is for STANDALONE workbooks only. The master workbook continues using documentation.py. Do NOT modify documentation.py.
