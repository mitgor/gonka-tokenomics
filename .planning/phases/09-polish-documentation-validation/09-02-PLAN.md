Create a new file `generators/print_setup.py` with two public functions:

**1. `apply_sheet_protection(wb, password='gonka')`**
Enables sheet-level protection on ALL worksheets. All cells default to locked in openpyxl; Phase 1 already set `Protection(locked=False)` on input cells. This just flips the sheet-level switch.

```python
def apply_sheet_protection(wb, password='gonka'):
    """Enable sheet protection on all worksheets.

    MUST be called AFTER all cell content is written and BEFORE saving.
    Input cells already have Protection(locked=False) from workbook_base.py.
    All other cells default to locked=True.
    """
    for ws in wb.worksheets:
        ws.protection.sheet = True
        ws.protection.password = password
        # Allow selecting cells (both locked and unlocked) for copy/view
        ws.protection.selectLockedCells = False
        ws.protection.selectUnlockedCells = False
        # Allow formatting operations (viewing, not content editing)
        ws.protection.formatCells = True
        ws.protection.formatColumns = True
        ws.protection.formatRows = True
```

**2. `apply_all_print_settings(wb)`**
Applies per-tab print settings to every worksheet based on tab name. Uses a dispatch dict mapping tab names to their print configuration.

Tab-specific print settings (from research):

| Tab Name | Print Area | Orientation | Title Rows | fitToHeight |
|----------|-----------|-------------|------------|-------------|
| Documentation | `A1:F{max_row}` (auto-detect) | portrait | None | 1 (fit single page) |
| Assumptions | `A1:E{max_row}` (auto-detect) | portrait | `1:3` | 0 (unlimited) |
| Emission Schedule | `A1:J38` | landscape | `1:2` | 0 |
| Token Price | `A1:L34` | landscape | `1:2` | 0 |
| Fee Transition | `A1:N47` | landscape | `1:2` | 0 |
| Host Profitability | `A1:M55` | landscape | `1:2` | 0 |
| Treasury & POL | `A1:N49` | landscape | `1:2` | 0 |
| Dashboard | `A1:E22` | portrait | None | 1 (fit single page) |
| Definitions | `A1:B{max_row}` (auto-detect) | portrait | None | 0 |

For tabs with `{max_row}` -- detect the max used row via `ws.max_row`.

For standalone workbooks, the same tab names are reused, so the dispatch handles both master and standalones.

For any unrecognized tab name (safety fallback): apply landscape, fit-to-width=1, fit-to-height=0, full worksheet print area.

Common settings for ALL tabs:
- `ws.page_setup.paperSize = ws.PAPERSIZE_LETTER`
- `ws.page_setup.fitToWidth = 1`
- `ws.page_setup.fitToPage = True`
- Page margins: left=0.5, right=0.5, top=0.75, bottom=0.75, header=0.3, footer=0.3
- Header center: `&A` (sheet name)
- Footer left: `Page &P of &N`
- Footer right: `Gonka Tokenomics v1.1`

Implementation approach: Create a helper `_apply_tab_print(ws, print_area, orientation, title_rows, fit_to_height)` that applies the common settings + tab-specific overrides. Then `apply_all_print_settings(wb)` iterates all worksheets, looks up config, and calls the helper.

Use a dict-based config pattern (not if/elif chains):
```python
# Static print areas for known model tabs
_PRINT_CONFIGS = {
    "Emission Schedule": {"area": "A1:J38", "orient": "landscape", "titles": "1:2", "fth": 0},
    "Token Price": {"area": "A1:L34", "orient": "landscape", "titles": "1:2", "fth": 0},
    # ... etc
}
```

For dynamic-area tabs (Documentation, Assumptions, Definitions), detect max_row.
