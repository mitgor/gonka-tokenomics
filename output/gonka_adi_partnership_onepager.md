# Gonka × ADI: Sovereign AI Inference on Abu Dhabi's Digital Rail

**One-pager for ADI Foundation / Sirius International Holding** · September 2026 · Draft for discussion

**The idea in one line.** ADI Chain becomes the regulated settlement and verification layer for Gonka's decentralized AI inference network, the way BNB Chain became a home for pegged USDC: not a takeover, a deep integration that brings a live AI workload, a developer audience, and GPU economics onto ADI, while Gonka gains a dirham-settled, institution-grade rail into the Middle East, Africa and Asia.

## What Gonka is (facts as of July 2026)

- Decentralized AI inference network. ~98% of network compute does real AI work (Sprint Consensus proof-of-compute), not idle hashing.
- $80M+ raised from Coatue and Bitfury Capital. Hosts include Gcore, Hyperfusion, 6blocks; GAIB runs turnkey H100/H200/B200 node operations. CertiK audits.
- OpenAI-compatible API, so any existing app or agent framework switches with a base-URL change. Serves frontier-class open models (Kimi K2.6 / K3 tier) at a fraction of closed-API prices.
- GNK token pays for inference and rewards GPU hosts. ~1,200 GPUs live today, so per-GPU mining share is high relative to the announced peak.

| **Settle** | A real, recurring payment flow (inference fees) settled in DDSC and GNK on ADI Chain | GNK issued on ADI Chain (bridged/wrapped), DDSC↔GNK liquidity, institutions pay for AI in dirham |

## Four practical integration tracks

1. **GNK on ADI Chain (settlement).** Deploy a bridged GNK asset on ADI Chain (Gonka already bridges GNK to Ethereum; if ADI Chain is EVM-compatible the contracts port directly). A licensed ADI participant custodies the bridge, consistent with ADI's "institutions provide the regulated service" model. Pair with DDSC so a bank, port or ministry buys AI compute in dirham and never touches a crypto exchange.
2. **Abu Dhabi inference cluster (operate + earn).** Sirius/IHC datacenter capacity runs Gonka nodes. Two revenue lines: GNK mining rewards on every epoch plus inference fees from real traffic. GAIB's private batch (200+ H200) reported $600K+ in its first phase; at today's ~1,200-GPU network a 500-GPU cluster is a top-tier host with proportional reward share. Hardware is standard H100/H200/B200; no custom silicon.
3. **"AI on ADI" developer distribution (promote the chain).** Publish an ADI-branded inference endpoint and MCP server that any agent can call, paid in DDSC via x402-style agent payments (x402 Foundation members include Visa, Mastercard, AWS, Coinbase). ADI becomes the first regulated chain where an AI agent buys compute in a central-bank-approved stablecoin. Gonka's developer channels (OpenClaw provider listing, MCP Registry, gateways like JoinGonka) carry the ADI name worldwide.
4. **Verifiable AI records (verify).** Anchor inference proofs to ADI for regulated use: an energy allocator, a trade-document classifier or a claims model can show *which model, which input hash, which verified host* produced a decision. Extends ADI's Good Energy pattern (113M+ records, private data stays with the owner) to AI outputs.
